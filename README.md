# Northstar Lens

Northstar Lens is a visual search app that helps users explore image ideas by topic. The interface is designed for a clean, calm browsing experience with a sticky header, quick-pick category chips, and a spacious results layout that adapts to any screen size.

This is the Part 1 UI scaffold for the project, focusing on the branded search shell and responsive empty results grid before the live image-fetching logic is added.

I chose a warm, earthy palette and a strong search-first layout so the app feels inviting without copying the reference design. The quick-pick row gives people a fast way to start exploring common themes like nature, cities, and travel.
